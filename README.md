# ExpenseTrackerBackend

This project was generated using Spring Boot with Java 17.

## Preparation
1. First put your Gemini API key into application.properties or add an environmental variable as GEMINI_API_KEY

2. To build the project go to:

```
menu > build > build project
```

## Development server

To start a local backend, go to ExpenseTrackerBackendApplication.java and click:

```
run
```

Once the server is running, open your browser and navigate to `http://localhost:8080/`. The application will automatically reload whenever you modify any of the source files.

## App features

App allows to add and show expenses related to driving a car:

```
adding expense
showing all expenses
generating "best gas station in specific loation"
```
